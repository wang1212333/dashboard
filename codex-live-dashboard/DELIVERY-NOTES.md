# 完整交付包说明（含内网实时分享）

本包是当前独立看板的完整源码快照，可替代之前不含分享功能的代码包。没有迁入 DSH，也没有包含整个 DSH 工程。

## 已包含

- MCP 连接、HTTPS/MCP 会话复用与真实数据查询。
- 日期、品牌筛选，指标、每日趋势、国家排名和明细。
- 两路受控并行、相同在途请求合并、耗时记录及轮转日志。
- 生成内网分享链接、1 小时/24 小时/7 天有效期、撤销、服务端固定日期品牌范围。
- 仅本机管理分享，访客通过链接授权查看并刷新数据。
- 配置占位示例、10 项自动检查、技术交接文档、分享使用说明及模板许可证。

## 阅读顺序

1. README.md：启动方式、数据口径、当前能力。
2. TECHNICAL-HANDOFF.md：从连接到页面的架构和代码入口。
3. SHARE-GUIDE.md：生成链接、访客范围、网络及失效规则。
4. config.example.toml：将占位字段合并到运行用户的 ~/.codex/config.toml；不要覆盖已有配置，也不要把真实令牌提交到项目。

## 在另一台电脑运行

需要 Python 3.11+、可访问 MCP 的网络，以及对应数据源和表的权限。启动命令为 `python server.py`，本机入口为 http://127.0.0.1:4319/ 。代码仍使用当前 SCM_SR_PRO / sql_chat.sql_chat_siso_d_en 的业务字段，换数据源需要适配连接、查询及指标，不是填地址即可连接任意业务表。

Windows 防火墙规则属于当前机器设置，不会随 ZIP 迁移。另一台机器需要按实际网络策略放行其 Python 程序的 TCP 4319；目前采用 Private 网络、LocalSubnet 来源。规则名称为 CodexLiveDashboard4319Private。仅启动服务不会自动修改新机器的防火墙，也不会自动发送分享消息。

同事访问要求服务持续运行，网络互通。本版 HTTP 内网分享不含 HTTPS、企业登录、开机自启、进程守护或公网部署。令牌只保存在服务内存中，服务重启会使现有链接失效，需重新生成；访问地址变化也需要重新分享。
