# 内网实时分享使用说明

## 分享人

1. 在本机打开 http://127.0.0.1:4319/ 并刷新页面。
2. 选日期和品牌，点击“立即刷新”，等待数据成功加载。
3. 点击“分享看板”，选择 1 小时、24 小时或 7 天有效期。
4. 点击“生成链接”，然后复制链接发给同事。本功能不会自动发送消息。
5. 在分享面板查看有效链接列表，点击对应“撤销链接”可停止后续访问。

同事持链接即可访问，所以只把链接发给有权查看该范围数据的人。访问使用分享人的 MCP 权限，并非同事自己的账号权限。当前固定分享的是已加载的日期和品牌；同事可以定时或手动更新这个范围内的数据，不能修改范围。固定结束日期不会自动向后滚动。库存仍取该期间最后一个有数据的业务日。

## 运行与网络条件

你的电脑必须保持开机、联网，Python 服务持续运行。默认仍每 5 分钟查询一次，业务更新取决于上游。分享链接不含 MCP 凭据，访问令牌用来换取 HttpOnly、SameSite=Lax Cookie；换取成功后地址栏跳转到首页，不再显示令牌路径。

本版是 HTTP 内网试用，尚未部署 HTTPS 或企业登录。Windows 已创建 CodexLiveDashboard4319Private 入站规则：Python 程序、TCP 4319、Private 网络、LocalSubnet 来源。它没有放行公网或所有公司网段。同子网同事访问仍可能受到公司无线隔离策略限制；跨子网访问应按实际网络范围配置规则或迁到正式内网服务器。未从其他物理电脑实测。

当前网络地址改变时，应重新生成链接。服务重启后全部链接失效，需要重新生成；有效期上限 7 天，最多 100 个有效链接。链接撤销和过期会拒绝后续页面/API 请求，但无法收回访客已经加载、截图或下载的数据。

## 实现

- sharing.py：32 字节随机 URL-safe 令牌，SHA-256 摘要存内存、有效期、撤销、固定筛选范围。没有把令牌持久化到磁盘。
- POST /api/shares：仅回环来源且 Host、Origin 匹配的 JSON 请求可以创建链接。
- GET /api/shares：仅分享人查看有效链接元信息；不返回历史链接令牌。
- POST /api/shares/revoke：仅分享人按链接 ID 撤销。
- GET /s/{token}：校验后设置 Cookie，303 跳转首页。响应 Referrer-Policy: no-referrer。
- GET /api/access：页面区分分享人与访客，访客显示固定范围和到期时间。
- GET /api/dashboard：访客的筛选参数由服务端覆盖为链接保存的范围；查询完成返回数据前再次核验链接有效性。
- 凭据配置变化后旧分享授权失效。MCP 访问令牌不会返回浏览器；日志不记录分享路径或 Cookie。

测试包含令牌摘要、到期、配置范围、撤销、未授权访问、管理接口来源保护和参数篡改。另通过本机实际内网 IP 测试链接跳转、Cookie、真实 MCP 查询和撤销后 403。测试链接已撤销。
