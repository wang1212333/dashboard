# 真实数据看板 · Codex 演示

打开 http://127.0.0.1:4319 。服务与 DSH 独立，现支持受分享链接保护的内网访问。操作说明见 SHARE-GUIDE.md。

若服务已停止，在此目录运行 `python server.py`（Python 3.11+，无额外依赖）。访问令牌从用户目录 `.codex/config.toml` 的 `mcp_servers.data-gateway` 读取，不复制到页面或项目文件。

选择日期或品牌后点击“立即刷新”执行只读 SQL，定时查询复用当前条件。MCP 会话按需初始化并复用。默认每 5 分钟刷新，可选 1 分钟或手动；页面隐藏时暂停定时查询。本机服务需要持续运行并能访问内网。

数据来自 SCM_SR_PRO 的 sql_chat.sql_chat_siso_d_en。已通过 list_tables 和 describe_table 核实访问权限和字段含义。首次打开默认发现最新业务日期，并回溯 30 天。页面支持自选起止日期（含首尾，最多 366 天，不超过上海时区今天）；自定义日期查询不再获取全表最新日期。

- SI：源表 si 按期间求和，保留负值。
- SO：源表 so，融合激活数（限两年发货），不是零售订单。
- 库存：total_stock_qty 仅在所选期间最后一个有数据的业务日汇总，不跨日累加。
- 数据覆盖国家：按 country_code 去重，包括零值记录。
- 排名：按 SI 降序取前十国家，不代表全部国家合计。
- 缺失日期在曲线上断开，不当成零。空值不当成零。
- 每次核对每日合计与整体汇总一致。源表会变化，多次查询无法保证数据库级同一事务快照，核对不一致会拒绝更新。

查询失败时前端保留上次成功结果，保持原时间戳并提示失败。首次失败不展示虚构数据。此页面不发布到公网，无任意 SQL 输入接口。

图表参考 Lieflat Charts 的 F2 Hairline Line（basics-gallery 的 B2 渲染块）及 F5 Tick Rows（C1 渲染块）。选择比较：L3 Barcode Lollipop 的高密度日历肌理不适合本次双序列短期比较；F6 Paired Rungs 适合离散分类双值，但 30–90 天逐日并排会过密；F2 保留每日刻度、发丝折线和周末空心点，F5 保留分段刻度、每五单位点标和行尾读数。排名根据数量级设定诚实的刻度单位，端点表示精确值。统一 Mono 灰阶。

## 通用查询执行优化

`query_runtime.py` 独立管理会话池、并发上限、执行中的相同请求合并和耗时日志。当前数据源最多同时执行 2 个查询，最多接收 8 组不同条件的执行中请求；超出返回 429。其他数据源可通过独立 QueryRuntime 和对应 client factory 接入，各自配置并发数。当前仅配置了 data-gateway，并非已接入任意数据源。

- 每个池槽独占一个 MCP 会话及 HTTPS 连接，避免同一客户端并发读写。JSON 响应复用 HTTP 连接；SSE 响应收到目标事件后关闭传输连接，后续保留 MCP 会话。失败会话被丢弃，下次查询重新建立；不自动重放未知操作。凭据配置变化后不复用旧会话。
- 品牌、每日趋势、国家排名受控并行；库存汇总等待趋势提供最后业务日期。自定义日期查询不再重复获取全表最新日期。
- 合并键包含凭据配置指纹、数据源、表、日期窗口和品牌。完成后立即移除，只合并正在执行的请求，不缓存已完成结果。多用户接入时必须由服务端认证提供权限上下文，不能使用浏览器传入的身份作为隔离依据；当前服务仍使用分享人的单一 MCP 凭据，分享访问由服务端限定日期和品牌。
- 接口包含 timings（各阶段排队、会话准备、查询耗时）、responseMs、sharedRequest。页面查询耗时文字的悬停提示可查看阶段耗时。
- performance.log 自动轮转，单份最多 2 MB，保留 3 份备份。仅记录执行编号、阶段、状态及耗时，不记录 SQL、筛选值、访问令牌和业务结果。

验证：8 项自动检查通过；真实接口验证首次及复用会话查询、3 个同时相同请求共享同一执行编号且结果相同。2026-09-01 至 2026-09-03 全品牌样本：改造前 1153 ms，改造后首次 545 ms、再次查询 217 ms；为单次本机样本，不作为所有数据源的性能保证。
