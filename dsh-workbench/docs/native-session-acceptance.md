## 当前路径

工作台输入 / 上传 → 独立真实 Workspace 原生 Session → SessionDriver.prompt → 工作台内嵌原生对话组件 → 原生工具保存草稿 → 工作台预览 → 用户明确确认发布。

- 不跳转到原生会话页。保留工作台导航、输入框、附件和模板选择。
- 新建任务使用独立原生 sessionId，不借用其他会话；续聊和刷新使用原 sessionId。
- 原生组件通过独立命名的扩展插槽组合挂载，使用原组件、原 store 和原交互；不搬移既有 DOM，不另建正文 SSE 投影。
- 每个任务只挂载一个原生历史区，旧版逐轮渲染不再重复创建对话区域。
- 用户输入与任务资源分离：用户消息不附加模板规范、本地路径或 SHA。每次提交保存不可变的附件/模板快照，原生 pre-step 注入有来源标记的简短资源上下文。
- 模板规范通过 workbench_get_task_context 按需读取；选择模板不等于要求搭建，普通问话不应擅自生成看板。
- 原生 SessionDriver 负责流式正文、工具执行、提问、审批及取消。交互页面不走 dashboard-agent-sessions 自定义 SSE，不创建 Headless Agent。
- 不设置“180 秒没有公开正文就取消”；运行状态来自原生会话。
- 恢复失败明确报错，不生成替代会话；未知提交结果不会静默重复执行。
- Windows 原子写入增加短暂文件占用重试，不删除或截断上一个有效快照。
- 不改模型、Key、发布权限或其他看板页面布局。

## 验收边界

真实链路使用合成小 CSV，没有重跑用户 5 万行生产数据。原生提问已实测；未人为制造生产权限审批。发布的正反例仅在自动化测试临时库执行，真实测试草稿未发布。

当前模型偶尔把 think 标签内容作为公开正文返回，原生 UI 同样会显示；本次不伪造或重新拆分模型事件，不声称已修复此上游内容格式问题。原生模型耗时、上游服务错误、工具连接和大数据分析质量不因本次接入而获得保证。

原生组件扩展接口发生不兼容时，需重新回归；组件渲染异常有局部错误边界。服务重启期间出现的第三方侧栏终端重连提示，与本次原生对话传输不是同一路径。
