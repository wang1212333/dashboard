# Project backup — 2026-09-15

This backup captures the current DSH workbench, standalone live dashboard,
server deployment tools, tests, and operational documentation.

Included capabilities:
- Persisted preflight plans and repeat-safe draft delivery.
- Automatic server deployment from the native publish action, signed receipts,
  retry handling, and server links in the dashboard catalog.
- Shared filter and SQL inspector rendering for local and server viewers.
- Live dashboard sharing and Feishu card integration.

Local credentials, runtime libraries and business data, logs, generated delivery
packages, and browser captures are excluded from this source backup. They remain
on the authoring machine. This is not a backup of the server's data or credentials.

Known limitations remain: company network and Jupyter authentication are required;
ordinary colleague/mobile access and container recreation recovery need further
acceptance; the model tool-name corruption issue is not confirmed resolved.

Validation for this snapshot: TypeScript type checking passed. Six selected server
publication/viewer/Feishu tests passed. The initial selected Vitest run passed 32
of 35 checks; three live-dashboard checks exceeded the default five-second timeout
and were rerun with a thirty-second limit. See the backup commit message for the
rerun outcome. No runtime behavior was changed as part of this backup.
